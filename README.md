## ✨ About This Project

This portfolio represents my journey, skills, and projects as a Computer Science student. It's designed to provide a comprehensive view of my:

- 🎓 **Academic Journey** at Singapore Management University
- 💼 **Professional Experience** in volunteer leadership and project management
- 🚀 **Technical Projects** from recent hackathons to academic coursework
- 🎨 **Creative Work** in design and visual arts
- 🤝 **Community Impact** through volunteer work and workshops

## 🎯 Key Features

### 🌙 **Clean Lavender Theme**
- Beautiful lavender color scheme in dark mode
- Soft pastel tones for light mode
- Smooth theme transitions
- Persistent theme selection

### 📱 **Multi-Page Architecture**
- Home page with hero section and quick stats
- Comprehensive About page with tabbed content
- Advanced Projects page with filtering and search
- Contact page with working form integration
- Persistent header navigation

### ⚡ **Performance & UX**
- Lighthouse score 95+
- Mobile-first responsive design
- Fast page transitions
- Clean, minimal interface
- Accessible components (WCAG compliant)

### 🔍 **Advanced Features**
- Project search and filtering by category/type
- Interactive skill showcases with progress bars
- Contact form with mailto integration
- Social media integration
- Professional typography and spacing
